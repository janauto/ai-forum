# 砺 / Forge · AI 研发工作空间

> 面向研发团队的 AI 工作助手原型 —— 融合项目管理、AI 对话、工具调用与 AI 会议的一体化工作台。

---

## 产品定位

**砺（Forge）** 是一个以「项目」为入口的 AI Coding IDE 形态工作助手，面向嵌入式软件工程师、产品经理等研发岗位，核心理念：

> **AI 是见证者，不是裁判。** AI 只陈述事实与历史数据，从不做最终判断，所有结论由人确认。

---

## 功能模块

| 模块 | 说明 |
|------|------|
| **工作台** | 项目卡片（按优先级排序）+ 实时 AI 对话（注入项目上下文）+ 待办弹出 + 快速插入 |
| **创作** | 按岗位推荐能力库，探索版工具，一键插入项目 |
| **案例库** | 三区：已验证 / 预研中 / 技术空白；失败案例平等收录 |
| **AI 会议** | 单人即可发起 → AI 主持对话 → 拆解为可解决/需协助/风险点 → FDE 审理 → 透传分发 |

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/janauto/forge-ai-workspace.git
cd forge-ai-workspace
```

### 2. 配置 API Key

```bash
cp .env.example .env
# 用编辑器打开 .env，填入你的 MiMo API Key
```

`.env` 内容示例：

```
MIMO_API_KEY=tp-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
MIMO_MODEL=mimo-v2.5-pro
MIMO_BASE=https://token-plan-cn.xiaomimimo.com/v1
PORT=8787
```

> **注意**：`.env` 已加入 `.gitignore`，不会被提交。**请勿将真实 Key 写入任何受版本控制的文件。**

### 3. 启动本地服务

```bash
node server.js
```

### 4. 打开原型

浏览器访问：[http://localhost:8787](http://localhost:8787)

> ⚠️ 请勿直接双击 HTML 文件（`file://` 协议无后端代理，AI 对话会失败）。

## 技术栈

| 层 | 技术 |
|----|------|
| 原型前端 | 单文件 HTML + 原生 CSS + 原生 JS（无构建工具）|
| 本地后端 | Node.js（内置 `http` 模块，零依赖）|
| AI 模型 | 小米 MiMo `mimo-v2.5-pro`（OpenAI 兼容接口，流式输出）|
| 部署形态 | 纯本地原型，无数据库，无登录 |

## 设计原则节选

1. **AI 作见证者** —— 输出只含事实，标注「事实·无判断」，结论由负责人确认
2. **项目是最小阻力入口** —— 所有 AI 功能从项目上下文出发，不需要空白起点
3. **AI 会议可单人发起** —— 无需预约他人，「参与人」是会后异步收到结果的干系人
4. **知识必须有主人** —— 案例库每条记录须绑定负责人，孤儿知识不入库

完整理念见 [`2026_06_AI研发提效产品理念思维册子.md`](2026_06_AI研发提效产品理念思维册子.md)
