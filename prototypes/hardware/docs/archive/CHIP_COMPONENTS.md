# 芯片组件添加完成说明

## ✅ 已完成的工作

### 1. **在 library.js 中添加了 4 种真实芯片组件**

#### 🔹 chip_mcu — 主控芯片
- **型号可选**：AW313A, IP5328, IP5389 等
- **交互**：可设置型号、开关机状态
- **显示**：芯片型号、运行状态（● 运行 / ○ 待机）、封装信息
- **事件**：overheat（过热）、ready（就绪）

#### 🔹 chip_pd — PD协商芯片
- **型号**：HUSB238（默认）
- **交互**：可触发电压协商（5V/9V/12V/20V）
- **显示**：实时协商电压、I2C地址
- **事件**：negotiate（协商）、voltage_change（电压变化）

#### 🔹 chip_gauge — 电量计芯片
- **型号**：CW2015（默认）
- **交互**：可更新 SOC 和电压值
- **显示**：电量百分比、电池电压（mV）
- **颜色**：低于 20% 显示红色告警

#### 🔹 chip_sensor — 通用传感器芯片
- **通用型**：可配置型号、接口类型（I2C/SPI）
- **交互**：可设置传感器数值和单位
- **显示**：实时数值 + 单位

## 🎮 如何使用

### 在左侧组件库中
现在可以看到新的 **"芯片"** 分类，包含：
- ⬛ 主控芯片
- ⬛ PD协商芯片
- ⬛ 电量计
- ⬛ 传感器芯片

### 拖拽到硬件视口
1. 从左侧拖拽芯片到 PCB 板上
2. 点击芯片可交互（如切换状态、更新数值）
3. 选中后在右侧属性面板可修改型号、参数

### 芯片间联动示例

**示例 1：充电流程**
```
[USB-C接口] --插入--> [chip_pd] --协商9V--> 触发 negotiate 事件
[chip_pd] --voltage_change--> [chip_mcu] --启动充电-->
[chip_mcu] --充电中--> [chip_gauge] --更新SOC-->
[chip_gauge] --soc_change--> [LED指示灯] --显示电量-->
```

**示例 2：电量监控**
```
[chip_gauge] --读取电池电压--> [chip_mcu] --计算SOC-->
[chip_mcu] --更新显示--> [OLED屏] --显示百分比-->
低电量 <20% --> [chip_gauge] 边框变红 + [蜂鸣器] 告警
```

## 🎨 视觉效果

### 芯片外观特征
- **主控芯片（AW313A）**：
  - 蓝色边框（运行时）/ 灰色边框（待机）
  - 左右两侧引脚装饰
  - 中央显示芯片型号 + 状态圆点
  - 底部显示厂商和封装

- **PD协商芯片（HUSB238）**：
  - 紫色边框（协商成功）/ 灰色边框（待机）
  - 显示当前协商电压（如 9V）
  - 底部显示 I2C 地址

- **电量计（CW2015）**：
  - 绿色边框（正常）/ 红色边框（低电）
  - 大字显示 SOC 百分比
  - 小字显示电池电压（mV）

- **传感器芯片**：
  - 中央显示传感器数值 + 单位
  - 底部显示接口类型和地址

## 📊 与原有组件对比

| 维度 | 原有组件（按键/LED） | 新增芯片组件 |
|------|---------------------|-------------|
| **抽象层级** | 功能层（GPIO输入/输出） | 架构层（真实芯片型号） |
| **交互性** | ✅ 可点击、可交互 | ✅ 可点击、可交互 |
| **视觉** | 拟物化（按键/灯泡） | 科技感（IC芯片外观） |
| **事件** | 通用事件（press/click） | 芯片特定事件（negotiate/soc_change） |
| **信息量** | 引脚/状态 | 型号/厂商/接口/实时数值 |
